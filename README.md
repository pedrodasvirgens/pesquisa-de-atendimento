# Pesquisa de Atendimento

## Sobre o projeto

O **Pesquisa de Atendimento** é um programa desenvolvido em Python para realizar uma pesquisa de opinião sobre o atendimento prestado aos clientes da empresa de marketing TudoWeb.

O sistema coleta o nome, a idade e a opinião de 50 entrevistados, utilizando opções de avaliação que variam entre EXCELENTE, BOM e RUIM.

Ao final da pesquisa, o programa apresenta a quantidade de respostas classificadas como EXCELENTE e RUIM.

## Objetivo

O objetivo do projeto é utilizar estruturas de repetição e estruturas de decisão em Python para desenvolver um sistema simples de pesquisa de satisfação.

## Como executar

1. Tenha o Python instalado em seu computador.
2. Abra a pasta `pesquisa-atendimento` no Visual Studio Code ou em outro editor.
3. Abra o arquivo `app.py`.
4. Execute o programa pelo terminal com:

    python app.py

5. Informe o nome do entrevistado.
6. Informe a idade.
7. Escolha uma das opções de atendimento:
   - `1` - EXCELENTE
   - `2` - BOM
   - `3` - RUIM

O programa realizará a pesquisa com 50 entrevistados e, ao final, apresentará a quantidade de respostas EXCELENTE e RUIM.

## Testes realizados

Antes da execução definitiva, o programa foi testado com 10 entrevistados para verificar o funcionamento da estrutura de repetição, das estruturas de decisão e dos contadores de respostas.

Durante os testes, foram utilizadas respostas variadas entre EXCELENTE, BOM e RUIM para verificar se a contagem das respostas estava funcionando corretamente.
